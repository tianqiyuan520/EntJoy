## 2. 删除口径（三个选项）

| 选项 | 动作 | 回收 | 风险 |
|---|---|---|---|
| **A（推荐）** | 删除**不含 `.ps1` 的 288 个目录**；保留 147 个脚本 + 7 个含脚本的目录 + 根目录文件 | **~702 MB (96%)** | 低：这些目录里没有任何脚本，删它们不会让任何脚本失效；输出可由重跑再生，结论已在 `docs/gridsearch/` 入库 |
| B | 先 `git add -f tools/gate-run/**/*.ps1` 打一个快照提交，再执行 A（脚本进库可恢复） | ~702 MB | 低，但会把 147 个一次性实验脚本**永久留在仓库里**，与"清理"目标相反 |
| C | 全删（含 147 个脚本） | 733.7 MB | **高**：脚本是重跑实验的唯一手段，删了就再也复现不了任何 A/B |

### 为什么 A 的风险低

1. **不破坏脚本**：被删的目录里**没有脚本**；脚本的输出目录是它自己 `New-Item -Force` 建出来的。
2. **不丢结论**：所有 A/B 的结论、否证记录、`原判错误` 更正都已写进 `docs/gridsearch/*`（已入库）。
3. **可再生成**：`.dll`/`.pdb`/`.obj` 由 git 里的源码重编译；`.cpp`/`.cs` 是转译器输出；
   `.asm` 是 `dumpbin` 反汇编；`.trx` 是 `dotnet test` 结果。
4. **唯一真实损失**：失去"本地回看某一次具体运行的原始日志"的能力；且个别 A/B 臂的
   `.dll` 是当时**未提交**的源码状态下构建的 ⇒ 无法逐字节复现那一臂（但结论已记录）。

### 需要保留的东西（执行 A 时不要碰）

- `tools/gate-run/*.ps1`（147 个）与 7 个含脚本的目录；
- `tools/gate-run/jobkeys.txt` —— **脚本的输入**（`count-probe.ps1` 把它当 `$KeyFile` 读）；
- 根目录下的其它非脚本小文件（提交信息草稿、键表等）。

## 3. 复现本清单

```powershell
# 体积与计数
Get-ChildItem tools\gate-run -Recurse -File | Measure-Object Length -Sum
# 逐个目录：文件数 / MB / 是否含脚本
Get-ChildItem tools\gate-run -Directory | ForEach-Object {
  $f = Get-ChildItem $_.FullName -Recurse -File -ErrorAction SilentlyContinue
  [pscustomobject]@{ Dir=$_.Name; Files=$f.Count
    MB=[math]::Round((($f|Measure-Object Length -Sum).Sum)/1MB,1)
    Scripts=($f|Where-Object Extension -eq '.ps1').Count }
} | Sort-Object MB -Descending
```

### 6.5 复现本节清单

```powershell
# 逐个构建目录：体积（删前先看这张表）
Get-ChildItem -Recurse -Directory | Where-Object { $_.Name -match '^(build|build-.*|artifacts|obj)$' } |
  ForEach-Object { $f = Get-ChildItem $_.FullName -Recurse -File -ErrorAction SilentlyContinue
    [pscustomobject]@{ MB=[math]::Round((($f|Measure-Object Length -Sum).Sum)/1MB,1); Path=$_.FullName } } |
  Sort-Object MB -Descending
# 谁在用（行号级，排除构建树自身）
Get-ChildItem -Recurse -File -Include *.ps1,*.yml,*.csproj,*.props,*.targets |
  Where-Object { $_.FullName -notmatch '\\(bin|obj|artifacts|build|build-[^\\]*)\\' } |
  Select-String -Pattern 'build-nativeDll-tests|build-lead|build-asan-msvc|NativeDllCore' 
```

⚠ **纪律（新增）**：`gates.ps1` 对 `build-lead` / `build-asan-msvc` 只 `cmake --build`（**不 configure**）
⇒ **删这两棵之前必须先 `cmake -S tests\NativeDll.Tests -B <dir>`**，否则门会以"没有构建树"的方式失败，
而且症状看起来像"测试挂了"而不是"少了目录"。
